# Slider comparison board

Mode: built-in image generation. One board comparing three proposals.

Use case: ui-mockup.
Create one detailed, polished design comparison board for Inner Breeze Android settings, proposing a reusable Kryon Material slider. Landscape high-resolution board, three equal columns, excellent precise typography, generous spacing. This is an implementable UI design proposal, not artwork, not a futuristic dashboard. Heading "Scale factor — three slider proposals". Small subtitle "Shared Kryon widget · Android". Background warm pale gray, dark near-black purple UI panels and matching light-mode panels. Lavender primary #CBAAFF in dark mode with dark ink #281442 on lavender chips; dark purple #6750A4 in light mode. No glows, glossy effects, 3D, shadows beyond subtle standard surfaces.
Each column has numbered title, large cropped Android Appearance settings preview with Style dropdown above and Navigation position below for alignment context, a matching small light-mode component preview, then a dragging/focus state component and concise annotation footer. Setting labels at same left margin throughout each preview. Slider label ALWAYS in its own header row, inside the component, above track, flush left with Style and Navigation position; value at far right of same header. Minus/plus controls in row below header, must never shift header to right. NO text printed on any track. Rounded horizontal track and round thumb, plausible classic Material 3 treatment. Common range 0.5× to 2.5×, default 1.0× means thumb exactly one-quarter across track; 1.5× means halfway. Readable values and spacious layout.
Column1 title "01 / Clear header" tag "Recommended". Header "Scale factor" left and plain lavender "1.0×" right. Below: neutral circular minus button, continuous thin lavender filled track with circular thumb at25%, muted unfilled track, neutral circular plus button. Tiny endpoint text below 0.5× left and 2.5× right aligned with track endpoints. Light version same geometry dark-purple accents. State sample label "Keyboard focus" showing thin focus ring around thumb, header1.0×. Footer annotations "Label aligned to settings edge", "Value stays above the track", "48 dp touch targets".
Column2 title "02 / Value chip". Same layout, but value1.0× in small softly lavender filled noneditable pill on header right, very dark purple text within; label remains left. Track slightly thicker rounded8dp, circular thumb at25%, minus/plus in neutral outlined circular controls. Matching light mode. State sample "Dragging" header chip1.5×, thumb halfway, modest state halo, no bubble. Footer annotations "Strong value contrast", "Stable header while dragging", "No value text on the fill".
Column3 title "03 / Discrete feedback". Same aligned header, plain1.0× right, thin track with subtle discrete ticks at equal steps, minus/plus below header aligned on row. Matching light mode. State sample "Dragging" header1.5× and tiny dark-ink-on-lavender value bubble1.5× above halfway thumb, reserved vertical space so bubble NEVER overlaps label/header. Footer annotations "0.1× steps", "Bubble only during interaction", "Header remains readable".
Bottom horizontal specification strip with title "Proposed core layout" and three clearly separated notes "Header → 12 dp gap → 48 dp interaction row", "Wrap long labels; grow height", "Theme label, value, track and thumb independently".
All listed dimensions are proposed design choices, not a claim of exact official Material specification. Prioritize clear realistic enlarged components over full phone mockups. Text must be sharp, exact, not tiny; every column must show visibly distinct but related slider designs. No logos needed.
